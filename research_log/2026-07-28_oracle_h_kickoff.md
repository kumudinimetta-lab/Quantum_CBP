# Oracle h Kickoff

## Task Framing
Implement a fixed-precision, gate-model reversible circuit for the LP relaxation bound h. Pair this with a formal correctness lemma bounding the precision loss.

## Plan
1. Locate and cite REAL primary sources for reversible division/multiplication.
2. Derive the precision lemma BEFORE writing simulation code.
3. Attempt a counterexample to the lemma.
4. Implement circuit and verify by exhaustive statevector simulation.
5. Classify all reported numbers.
6. Detail which instances/seeds/precision level were checked for correctness claims.
